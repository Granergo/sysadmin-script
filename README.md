# Б - Монитор ресурсов

Небольшой Bash-скрипт для периодического мониторинга ресурсов Linux.

## Что делает скрипт

Скрипт каждые `N` секунд записывает в `monitor.log`:

- информацию об оперативной памяти (`free -h`);
- использование дисков (`df -h`);
- время работы системы и нагрузку (`uptime`).

Каждый блок начинается с временной метки.

## Настройка

Интервал захардкожен в скрипте переменной N

## Для сборки Docker-образа

Docker-образ для работы скрипта можно собрать из Dockerfile
